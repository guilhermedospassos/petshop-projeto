# PetShop — protótipo de site

Projeto web de estudo com páginas para apresentar produtos e serviços de um pet shop. O objetivo foi praticar a organização de um site com múltiplas páginas, estilização em CSS e interações simples em JavaScript.

## Páginas e funcionalidades

- **Início:** apresentação do pet shop e navegação para outras seções.
- **Produtos e serviços:** páginas dedicadas ao catálogo e aos serviços.
- **Cadastro de pet:** interface para preenchimento de dados do animal.
- **Agendamento:** interface de agendamento de serviços.
- **Minha conta:** interface dedicada à área do usuário.

> Este repositório é um protótipo de front-end. As telas não devem ser interpretadas como um sistema comercial completo, com autenticação, pagamentos ou persistência de dados em servidor.

## Tecnologias

HTML5, CSS3 e JavaScript.

## Como visualizar

1. Clone o repositório:
   ```bash
   git clone https://github.com/guilhermedospassos/petshop-projeto.git
   ```
2. Abra o arquivo `index.html` no navegador.
3. Navegue entre as páginas disponíveis. Para desenvolvimento, também é possível usar um servidor local simples, como a extensão Live Server no VS Code.

## Estrutura principal

- `index.html` — página inicial
- `produtos.html` e `servicos.html` — catálogo e serviços
- `cadastro-pet.html` e `agendar-servicos.html` — formulários de interface
- `minhaConta.html` — área do usuário
- `css/`, `img/` e arquivos `.js` — estilos, imagens e interações

## Status

Projeto de estudo preservado como registro da minha evolução em desenvolvimento web. Novos recursos de backend, persistência e autenticação exigiriam implementação e validação adicionais.
